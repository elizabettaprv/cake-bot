# Cake-bot

Бот-консультант первой линии для кондитерской: отвечает на вопросы клиентов, собирает данные заказа и передаёт человеку то, что не должен решать сам.

## Задача

- Кондитерская в городе X (Испания), доставка в радиусе 100 км.
- Языки: русский и испанский. Клиенты пишут онлайн откуда угодно, заказы принимаются только в зоне доставки.

- Объём: 100–140 обращений в неделю (15–20 в день). Цифры предварительные.
- Сейчас отвечает человек по шаблонам. Цель — снять с него повторяющиеся вопросы.

## Метрики успеха

- Доля обращений, закрытых без человека. Целевое значение определим после evals.
- Полнота данных лида (заказа).
- Ноль ошибочных ответов в зоне риска (аллергены): ошибка здесь стоит здоровья клиента.

## Архитектура v1

- Workflow, а не автономный агент.
- Двухслойный роутер: сначала правила (бесплатно и предсказуемо), затем LLM-классификатор для того, что правила пропускают (другой язык, опечатки, перефразы).
- Четыре ветки: факты бизнеса, общие вопросы, заказ, риск.
- Три рубежа защиты по аллергенам: правила → LLM-классификатор → база знаний, где аллергены помечены «отвечает только человек».

## Ключевые решения

**Workflow, а не автономный агент.**
Сценарии обращений известны заранее, а часть вопросов связана со здоровьем клиента (аллергены). Путь обработки задаёт код, а не модель: так поведение бота предсказуемо и его можно проверить тестами. Автономия модели здесь добавляет риск, но не добавляет пользы.

**Один бот, без мультиагентной схемы.**
Задача не настолько сложная, чтобы делить её между несколькими агентами. Лишние вызовы моделей увеличивают стоимость и время ответа, ничего не давая взамен.

**Риски ищем широко, команду «стоп» — узко.**
Правила для `risk` ищут по части слова («орех», «аллерг»), чтобы поймать все формы. Лишнее срабатывание здесь дешёвое: вопрос просто уйдёт человеку. Правила для `stop` ищут только целое слово, чтобы «стопка блинчиков» не сбрасывала диалог. Лишнее срабатывание здесь дорогое: клиент теряет уже собранный заказ.

## Статус

Готово:
- `rules.py`: функция `detect_rule_intent`, возвращает `risk`, `stop` или `None`.

Дальше:
- LLM-классификатор (второй слой роутера).
- База знаний.
